# 山西财经大学本科学年论文格式规则详解

> 依据：附件1《山西财经大学本科学年论文内容与格式规范》

---

## 一、页面设置

| 项目 | 参数 | python-docx 实现 |
|------|------|-----------------|
| 纸张 | A4 (210mm×297mm) | `WdPaperSize.A4` |
| 上边距 | 3cm | `section.top_margin = Cm(3)` |
| 下边距 | 2.5cm | `section.bottom_margin = Cm(2.5)` |
| 左边距 | 2.5cm | `section.left_margin = Cm(2.5)` |
| 右边距 | 2cm | `section.right_margin = Cm(2)` |
| 文档网格 | 无网格 | 默认 |
| 字符间距 | 缩放100%，标准间距 | 默认 |

## 二、页眉页脚

- **页眉内容**：`山西财经大学20XX级本科生学年论文`（"XX"替换为实际年级）
- **页眉字体**：小五号宋体 (9pt)
- **奇数页**：右对齐
- **偶数页**：左对齐
- **封面、扉页、学术承诺**：不设页眉
- **页码**：正文用阿拉伯数字，奇数页右下角，偶数页左下角
- **摘要/目录**：页码用罗马数字 (i, ii, iii...)
- **封面/扉页/学术承诺**：不加注页码

## 三、封面

- 学校统一格式，内容打印填列
- 题目、姓名、学号、班级、年级、专业、学院、指导教师姓名及职称、完成时间

## 四、学术承诺与使用授权说明

- 内容由学校统一拟定
- 作者签名、指导教师签名和日期必须**中文手写**

## 五、中文摘要

| 项目 | 格式 |
|------|------|
| "摘要"标题 | 小二号宋体(18pt)，加粗，居中，字间空两格 |
| 段前段后 | 各空一行 |
| 摘要内容 | 小四号宋体(12pt)，与正文版面相同 |
| 字数 | 500字左右 |

## 六、英文摘要

| 项目 | 格式 |
|------|------|
| "Abstract"标题 | 三号Times New Roman(16pt)，加粗，居中 |
| 段前段后 | 各空一行 |

## 七、关键词

**中文关键词：**
- "关键词"三字：四号黑体(14pt)，前空两格，后接全角冒号"："
- 关键词内容：小四号宋体(12pt)，3~5个，用分号"；"分隔
- 段前空一行

**英文关键词：**
- "Key words"：四号Times New Roman(14pt)，加粗，左顶格，后接英文冒号":"
- 关键词内容：小四号，英文分号";"分隔

## 八、目录

| 项目 | 格式 |
|------|------|
| "目录"标题 | 小二号宋体(18pt)，加粗，居中，字间空两格 |
| 段前段后 | 各空一行 |
| 目录内容 | 小四号宋体(12pt)，列至二级标题 |
| 一级标题 | 左顶格 |
| 二级标题 | 左边缩进两个空格 |
| 页码 | 右顶格对齐，中圆点填充 |

## 九、正文

### 基本要求
- 总字数不少于5000字
- 导论部分1000字左右，论文主体及结语4000字左右

### 段落格式

| 项目 | 格式 |
|------|------|
| 正文字体 | 小四号宋体 (12pt) |
| 首行缩进 | 2字符 |
| 段前段后 | 0行 |
| 行距 | 1.25倍 |

### 标题格式

| 级别 | 字体 | 字号 | 加粗 | 对齐 | 段前段后 |
|------|------|------|------|------|----------|
| 一级标题 | 黑体 | 三号(16pt) | 加粗 | 居中 | 各1行 |
| 二级标题 | 宋体 | 四号(14pt) | 加粗 | 左顶格 | 0行 |
| 三级标题 | 宋体 | 小四号(12pt) | 加粗 | 左顶格 | 0行 |

标题序号与标题内容之间空一格。

## 十、注释

- 脚注形式，小五号宋体(9pt)
- 每页从"1"起重新编号
- 阿拉伯数字上标编号

## 十一、参考文献

### 基本要求
- 不少于10项（至少含3部以上著作）
- 另起一页
- "参考文献"：三号宋体(16pt)，加粗，居中，段前段后各空一行
- 内容字体：小四号宋体(12pt)
- 排序：中文在前，外文在后，按第一作者姓氏拼音/字母增序

### 著录格式

**期刊：** `[序号] 主要责任者．文献题名[J]．刊名，出版年份，(期号)：起止页码．`

**专著：** `[序号] 主要责任者．文献题名[M]．出版地：出版者，出版年：起止页码．`

**学位论文：** `[序号] 主要责任者．文献题名[D]．保存地：保存单位，年份．`

**报纸：** `[序号] 主要责任者．文献题名[N]．报纸名，出版日期(版次)．`

**论文集：** `[序号] 主要责任者．文献题名[C]．主编．论文集名．出版地：出版者，出版年：起止页码．`

**电子文献：** `[序号] 主要责任者．电子文献题名[EB/OL]．获取地址，发表或更新日期/引用日期．`

### 文献类型标识

| 类型 | 标识 | 类型 | 标识 |
|------|------|------|------|
| 专著 | M | 论文集 | C |
| 期刊文章 | J | 学位论文 | D |
| 报纸文章 | N | 报告 | R |
| 标准 | S | 专利 | P |
| 数据库 | DB | 计算机程序 | CP |
| 电子公告 | EB | | |

## 十二、致谢

- 另起页
- "致谢"：三号宋体(16pt)，加粗，居中，字间空两格，段前段后空一行
- 内容版面与正文相同

## 十三、装订顺序

1. 封面 → 2. 扉页 → 3. 学术承诺 → 4. 中文摘要关键词 → 5. 英文摘要关键词 → 6. 目录 → 7. 正文 → 8. 参考文献 → 9. 附录 → 10. 致谢 → 11. 成绩评定表
