# 段落拆分器 (Paragraph Splitter)

## 概述

从 PDF 转换或网页复制内容到 Word 时，经常出现多个段落被合并成一个长段落的问题。本技能自动检测并按规则拆分这些粘连段落。

## 适用场景

1. PDF 转 Word 后标题和正文混在同一段落
2. 网页复制内容段落边界丢失
3. 多个独立段落意外粘连

## 工作流程

### 步骤 1：分析文档

运行检测脚本，识别需要拆分的段落：

```bash
python paragraph_splitter.py <论文.docx> --detect
```

### 步骤 2：执行拆分

```bash
python paragraph_splitter.py <论文.docx> --split
```

### 步骤 3：验证

```bash
python paragraph_splitter.py <论文.docx> --report
```

## 拆分规则

按以下模式在段落内部换行处 (`\n`) 进行拆分：

| 规则 | 模式 | 示例 |
|------|------|------|
| 一级标题 | `\n数字+空格+文字` | `\n1  引  言` |
| 二级标题 | `\n数字.数字+空格+文字` | `\n1.1  研究背景` |
| 三级标题 | `\n数字.数字.数字+空格+文字` | `\n1.1.1  方法` |
| 中文标题 | `\n中文数字+、+文字` | `\n一、绪论` |
| 特殊节 | `\n(摘要\|Abstract\|目录\|参考文献\|致谢\|附录)` | `\n参考文献` |

## 参数

| 参数 | 说明 |
|------|------|
| `--detect` | 仅检测，报告粘连段落 |
| `--split` | 检测并拆分 |
| `--report` | 拆分后统计报告 |
| `--min-length 200` | 最小粘连检测长度（默认200字符） |
| `--output <path>` | 指定输出路径 |
